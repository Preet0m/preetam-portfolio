Selected project / Platform engineering

Production-Grade GitOps Delivery Platform

KubernetesArgoCDHelmKustomizeGitHub ActionsPrometheus/GrafanaArgo RolloutsVaultOPATrivy/Semgrep

A full delivery platform built the way production teams run Kubernetes: nobody runs kubectl apply by hand. Every change to the cluster flows through a Git commit, and ArgoCD continuously reconciles running state back to what the repository says it should be.

  • Containerized a Flask service with health and /metrics endpoints, unit tests, and a slim Docker image.
  • Built a GitHub Actions pipeline that runs tests, Semgrep SAST, image build and push, Trivy image scanning, then commits the new image tag back into the staging overlay.
  • Packaged the workload two ways — raw manifests with Kustomize overlays for staging and prod, plus an equivalent Helm chart with Deployment, Service, Ingress and HPA.
  • Configured ArgoCD Applications with auto-sync for staging and manual promotion for production.
  • Wired observability end to end: ServiceMonitor scraping, Prometheus alert rules on error rate and latency, and a custom Grafana dashboard.
  • Extended it with Argo Rollouts canary deploys that auto-abort on metric regression, Vault-issued short-lived secrets instead of static K8s Secrets, chaos pod-kill experiments, and OPA policies rejecting insecure manifests at admission.
  • Autoscaling handled by an HPA driven by CPU load under generated traffic.

Outcome: a single repository covering CI/CD, GitOps, progressive delivery, observability, secrets management, chaos engineering and policy-as-code — the modern DevOps/SRE toolchain, working together.
